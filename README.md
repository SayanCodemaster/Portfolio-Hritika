# Hritika Portfolio

A responsive single-page portfolio website showcasing Hritika Dam as a media personality, event host, anchor, and content creator.

## Overview

- Static HTML portfolio built with `index.html`
- Uses Tailwind CSS via CDN for layout, styling, and responsive design
- Includes local media assets for hero imagery, gallery photos, and promotional videos
- Designed for a polished, modern aesthetic with glassmorphism effects and gradient highlights

## Project Contents

- `index.html` - main portfolio page
- `hero.jpeg` - hero section image
- `about.jpeg` - about section image
- `gallery1 (1).jpeg`, `gallery1 (2).jpeg`, `gallery2.jpeg`, `gallery3.jpeg`, `gallery4.jpeg`, `gallery5.jpeg` - gallery photos
- `video1.mp4`, `video2.mp4`, `video3.mp4` - promotion campaign videos
- `.git/` - Git repository metadata

## Features

- Fixed navigation with anchor scrolling
- Hero section with responsive image and call-to-action buttons
- About section with stats and profile description
- Experience / timeline cards
- Photo gallery with hover animations
- Video promotion cards with autoplay looped previews
- Contact section with social links and contact form UI
- Skills section highlighting hosting, anchoring, and brand promotion strengths

## How to View

1. Open `index.html` in a web browser
2. Or serve the folder with a local HTTP server

### Example using Python

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Notes

- The site is fully static and does not require a build process
- External fonts and Tailwind CSS are loaded via CDN
- Contact form is present for UI only and does not include backend submission handling
